# Ícones de Sintomas para Receita Facilitada

Esta pasta deve conter os ícones de sintomas/indicações para as receitas visuais.

## Ícones Sugeridos (salvar como PNG ou SVG):

1. **dor_cabeca.png** - Ícone de cabeça com dor (enxaqueca, cefaleia)
2. **dor_corpo.png** - Ícone de corpo com dor (dores musculares, fibromialgia)
3. **febre.png** - Termômetro indicando febre
4. **pressao_alta.png** - Ícone de pressão arterial alta (hipertensão)
5. **diabetes.png** - Ícone de gota de sangue/glicosímetro
6. **colesterol.png** - Ícone de coração/colesterol
7. **infeccao.png** - Ícone de bactéria/vírus (antibióticos)
8. **alergia.png** - Ícone de espirro/alergia respiratória
9. **asma.png** - Ícone de pulmão/respiração
10. **estomago.png** - Ícone de estômago (gastrite, refluxo, digestão)
11. **intestino.png** - Ícone de intestino (prisão de ventre, diarreia)
12. **coracao.png** - Ícone de coração (cardiológico)
13. **ansiedade.png** - Ícone de cérebro/ansiedade
14. **insonia.png** - Ícone de lua/sono (distúrbios do sono)
15. **vitaminas.png** - Ícone de suplemento/vitaminas
16. **antiinflamatorio.png** - Ícone de inflamação
17. **anticoncepcional.png** - Ícone feminino/contracepção
18. **tireoide.png** - Ícone de tireoide/metabolismo
19. **ossos.png** - Ícone de ossos/articulações (osteoporose)
20. **vista.png** - Ícone de olho/visão
21. **ouvido.png** - Ícone de ouvido/audição
22. **pele.png** - Ícone de pele/dermatológico
23. **urina.png** - Ícone de bexiga/urinário
24. **gripe.png** - Ícone de gripe/resfriado
25. **tosse.png** - Ícone de tosse/expectorante
26. **nausea.png** - Ícone de náusea/vômito
27. **dor_dentes.png** - Ícone de dente/dor odontológica
28. **colirio.png** - Ícone de colírio/olhos
29. **pomada.png** - Ícone de pomada/uso tópico
30. **sos.png** - Ícone de emergência/SOS (somente se necessário)

## Especificações dos Ícones:
- Formato: PNG ou SVG
- Tamanho recomendado: 128x128 pixels ou vetorial
- Fundo: Transparente
- Cores: Alto contraste para melhor visualização
- Estilo: Simples e intuitivo para pacientes com baixo letramento

## Como Adicionar:
1. Baixe ícones gratuitos de sites como Flaticon, Icons8 ou Noun Project
2. Renomeie conforme a lista acima
3. Salve nesta pasta: `/public/img/n/f/`
4. O sistema carregará automaticamente ao selecionar a indicação no formulário
